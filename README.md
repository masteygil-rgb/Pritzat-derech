# פריצת דרך — קן דן ירדן

אתר מידע ויזואלי על מיזם **מנהרת ראש העין–פצאל**: חיבור אסטרטגי בין גוש דן, בקעת הירדן וציר הסחר הבין-יבשתי (IMEC).

## תוכן האתר
אתר בעברית (RTL) הבנוי בטאבים וטאבי-משנה, עם תפריט צד מעוצב:

1. **העתיד כבר כאן** — עמוד שער וחזון
2. **החזון האורבני** — מטרופולין המחר
3. **מנוע הצמיחה** — מודל כלכלי PPP/BOT וזרימת הון גלובלית
4. **המעבדה** — התפלה, אנרגיה מתחדשת ו-AI
5. **צומת העולם** — הגאופוליטיקה של ציר IMEC
6. **תשתית הביצוע** — ROI, שלבי פיתוח ותיאור הנדסי
7. **המהפכה הכחולה-ירוקה** — תעלת הימים ואגמים
8. **קריאה לפעולה** — הצטרפות ומפת דרכים ל-2050

## טכנולוגיה
HTML / CSS / JavaScript עצמאי — ללא תלויות build. פתיחה ישירה של `index.html` בדפדפן.

- `index.html` — מבנה האתר
- `assets/css/style.css` — עיצוב (פלטת צבעי הלוגו)
- `assets/css/admin.css`, `assets/js/admin.js` — מצב עריכה (אדמין)
- `assets/js/app.js` — ניווט, טאבים ואנימציות
- `assets/img/` — לוגו, צילומים (`site/`, `photos/`) ואיורים (`scenes/`)

## מצב אדמין
עריכת תוכן, עיצוב טקסט ותמונות ישירות בדפדפן — כניסה בכפתור ✎ או `?admin=1`.
